# 项目状态管理

## 查看状态
1. 列出 `projects/` 下所有项目目录
2. 读取各项目的 `PROJECT.md` 看板
3. 向用户报告：项目名、当前阶段、已完成产出物、待办、阻塞项（缺什么输入）

## 更新状态
每次阶段推进后更新 `PROJECT.md`：
```markdown
# 项目：<名称> (<slug>)
- **当前阶段**：<N>/<9> <阶段名>
- **PICO**：<一句话>
- **注册号**：<PROSPERO ID 或 "未注册">
- **已完成**：[x] 阶段清单（附产出物路径）
- **进行中**：<当前工作>
- **待用户输入**：<阻塞项>
- **关键决定记录**：<日期>: <决定>（如主要结局变更、模型选择）
```

## 接手项目（新会话）
1. 读 `PROJECT.md` + protocol + 最近的分析日志
2. 核对产出物完整性（文件是否都在）
3. 向用户确认："项目当前在 X 阶段，上次完成 Y。接下来做 Z，对吗？"

## 多项目管理
用户有多个项目时，报告用表格对比。默认操作用户最后提到的项目；歧义时先问。
